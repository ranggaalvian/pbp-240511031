# Analisis Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Arsitektur | Client-server: browser (front-end) berkomunikasi dengan server (back-end) lewat HTTP | Aplikasi standalone yang berjalan langsung di OS dengan akses penuh ke sumber daya lokal | Berjalan di OS mobile (Android/iOS), sering terhubung ke API/server, dengan akses sensor perangkat |
| Bahasa Utama | HTML, CSS, JavaScript (front-end); Node.js, PHP, Python (back-end) | Java, C#, C++, Python | Kotlin/Java (Android), Swift (iOS), Dart/Flutter, JavaScript/React Native |
| Distribusi | Diakses lewat URL di browser, tanpa instalasi | Installer (.exe, .msi, .dmg, .deb) atau file JAR | Google Play Store / App Store atau file APK |
| Keunggulan | Lintas platform, mudah diperbarui, tanpa instalasi | Performa tinggi, bisa offline, akses penuh ke perangkat keras | Portabel, memakai sensor (GPS, kamera), notifikasi push |
| Keterbatasan | Bergantung pada internet dan browser, akses perangkat keras terbatas | Harus diinstal, bergantung pada OS, pembaruan manual | Layar kecil, sumber daya terbatas, wajib mengikuti kebijakan store |
| Contoh Aplikasi | Google Docs, Tokopedia (web), Wikipedia | Visual Studio Code, Microsoft Word, IntelliJ IDEA | WhatsApp, Gojek, Instagram |
